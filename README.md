# AI Broadcaster privacy policy

**Read it live: <https://blixvip.github.io/ai-broadcaster-privacy/>**

Public privacy notice for AI Broadcaster 1.7.0, published by Kaihan under the Chrome Web Store display name `kaihanwasely`.

Support: [kaihanwasely@gmail.com](mailto:kaihanwasely@gmail.com).

This repository contains the policy page and its stylesheet only. It does not contain the extension source ([blixvip/ai-broadcaster](https://github.com/blixvip/ai-broadcaster)), developer credentials, identity documents or user conversations.

GitHub Pages serves `index.html` from the root of `main`. No build step, JavaScript, external fonts or analytics scripts are used. Open `index.html` locally to preview changes; verify narrow and wide layouts before publishing.

Comment to claim one. Pull requests get reviewed within a couple of days, and every contributor is credited in the release notes.
